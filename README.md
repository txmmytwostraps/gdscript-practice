# GDScript Practice

A small website for practising GDScript, the scripting language of the Godot game engine. You get a short problem, write a `solve()` function in the browser, press Run, and the tests tell you what passed.

Live site: https://txmmytwostraps.github.io/gdscript-practice/

## What it does

- 248 short problems on the fundamentals: variables, functions, conditions, arrays, strings, 2D vectors, frame timing with delta, and rectangles. Each has a prompt, starter code, a hint, and tests you can see.
- Your code runs in a real Godot engine inside the page, so results are exactly what Godot would give.
- Progress, a day streak, and half-finished code are saved in the browser. Sign in (GitHub or email) to keep them in sync across computers.

## How it is put together

- `judge/` is a Godot 4.7 project that compiles submitted code at runtime, runs its `solve()` against a problem's tests, and reports the results. It is exported to the web and embedded in the page.
- `problems/` holds one JSON file per problem. `index.json` lists them and is generated by `tools/build-index.js`.
- `site/` is the page: static HTML, CSS and JavaScript, no build step.
- `supabase/schema.sql` creates the table that stores signed-in users' progress.
- The GitHub Actions workflow validates every problem with the headless judge, exports the judge, and publishes the site on each push.

## Running it locally

Requirements: Node.js, and Godot 4.7.2 with the web export templates installed.

```
godot --headless --path judge -- --problems        # check every problem
godot --headless --path judge --export-debug WebNoThreads   # export the judge to web/
node tools/serve.js                                # serve the folder on http://localhost:8060
```

Then open http://localhost:8060/site/ in Chrome.

## Adding a problem

Copy any file in `problems/`, give it a new `id` matching the file name, write the prompt, starter, tests, hint and a reference solution, then run the validator above. It refuses problems whose solution fails a test or whose starter already passes.
